# Покер-рум для своих

Холдем (безлимит) и Омаха на 5 картах (пот-лимит) на виртуальные фишки.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm test          # все тесты
npm start         # сервер на http://localhost:3000
```

### Настройки (переменные окружения)

| Переменная | Что делает | По умолчанию |
| --- | --- | --- |
| `PORT` | Порт сервера | `3000` |
| `DB_PATH` | Файл базы данных | `data/poker.db` |
| `REGISTRATION_CODE` | Код приглашения: без него зарегистрироваться нельзя | не задан (регистрация открыта) |
| `COOKIE_SECURE` | `1`, когда сайт работает по HTTPS | выключено |
| `TRUST_PROXY` | `1`, когда сервер стоит за nginx или другим прокси | выключено |

## Устройство

**Движок** (`src/engine`) — правила покера, без сети и базы:

- `cards.ts` — колода, криптографическая тасовка Фишера–Йетса, хэш-коммит колоды для проверки честности.
- `evaluator.ts` — сравнение рук; в Омахе строго 2 карты с руки + 3 со стола.
- `hand.ts` — одна раздача: блайнды, торговля NL/PL, минимальные рейзы, неполные олл-ины, сайд-поты, делёж банка.
- `table.ts` — кэш-стол: места, бай-ин и докупка, стек сохраняется за ушедшим игроком до закрытия стола, статистика.
- `stakes.ts` — уровни блайндов: 10/20, 25/50, 50/100, 100/200, 200/500.

**Сервер** (`src/server`):

- `db.ts` — база SQLite (встроена в Node.js, ничего ставить не нужно).
- `auth.ts` — аккаунты, пароли (scrypt), сессии в cookie, ограничение попыток входа.
- `friends.ts` — заявки в друзья.
- `tables.ts` — живые столы: автостарт раздач, таймер хода, сохранение стеков и истории раздач в базу, восстановление после перезапуска.
- `app.ts` — HTTP API и WebSocket для игры в реальном времени.

### HTTP API

| Метод и путь | Что делает |
| --- | --- |
| `POST /api/register` | `{username, password, displayName, inviteCode}` |
| `POST /api/login` / `POST /api/logout` | Вход и выход |
| `GET /api/me` | Текущий пользователь |
| `GET /api/config` | Уровни блайндов, виды покера, нужен ли код приглашения |
| `GET /api/users/search?q=` | Поиск людей по логину или имени |
| `GET /api/friends` | Друзья, входящие и исходящие заявки |
| `POST /api/friends/request` | `{username}` — отправить заявку |
| `POST /api/friends/:id/accept` / `remove` | Принять / отклонить, отменить или удалить |
| `GET /api/tables` | Лобби: открытые столы мои и друзей |
| `POST /api/tables` | `{name, variant: NLH/PLO5, maxSeats, stakeId, minBuyInBB, maxBuyInBB, actionTime}` |
| `GET /api/tables/:id/stats` | Статистика стола (и после закрытия) |

### WebSocket `/ws`

Клиент отправляет: `join {tableId}`, `sit {seat, buyIn?}`, `stand`, `sit_out`, `sit_in`,
`add_chips {amount}`, `action {action: {type, amount?}}`, `close`.

Сервер присылает `state` — состояние стола глазами этого игрока (чужие карты скрыты),
`error {message}` и `closed {stats}`.

**Интерфейс** (`public`) — чистый JavaScript без сборки:

- `js/app.js` — вход, регистрация, лобби, друзья, создание стола, итоги.
- `js/table.js` — экран стола: места, карты, ставки, таймер хода, статистика, проверка честности колоды.
- `js/cards.js` — отрисовка карт (четырёхцветная колода) и подсказка текущей комбинации.
- `styles.css` — оформление; сначала под телефон, на компьютере стол шире.
- `fonts/` — шрифт Onest (лицензия SIL OFL, см. `fonts/OFL.txt`).
