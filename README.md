# Покер-рум для своих

Холдем (безлимит) и Омаха на 5 картах (пот-лимит) на виртуальные фишки.

## Что готово

**Этап 1 — покерный движок** (`src/engine`):

- `cards.ts` — колода, криптографическая тасовка Фишера–Йетса, хэш-коммит колоды для проверки честности.
- `evaluator.ts` — сравнение рук; в Омахе строго 2 карты с руки + 3 со стола.
- `hand.ts` — одна раздача: блайнды, торговля NL/PL, минимальные рейзы, неполные олл-ины, сайд-поты, делёж банка.
- `table.ts` — кэш-стол: места, бай-ин и докупка, стек сохраняется за ушедшим игроком до закрытия стола, статистика стола.
- `stakes.ts` — уровни блайндов: 10/20, 25/50, 50/100, 100/200, 200/500.
